# Fonte de Dados

- **Dataset:** Brazilian E-Commerce Public Dataset by Olist
- **Fonte:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- **Licença:** CC BY-NC-SA 4.0
- **Período coberto:** 2016–2018
- **Escopo:** ~100 mil pedidos realizados em múltiplos marketplaces brasileiros através da Olist

## Descrição

O dataset é composto por 9 tabelas relacionais contendo informações sobre pedidos, itens, clientes, produtos, vendedores, pagamentos, avaliações (reviews) e geolocalização. Os dados são reais, porém anonimizados — referências a empresas e parceiros foram substituídas por nomes de casas da série *Game of Thrones*.

## Observações de uso

- Uso permitido para fins não comerciais, com atribuição, sob a mesma licença (CC BY-NC-SA 4.0).
- Ao publicar o projeto (ex. portfólio, GitHub), citar a fonte original acima.
- Consultar `docs/data_dictionary.md` para o detalhamento de cada tabela.
